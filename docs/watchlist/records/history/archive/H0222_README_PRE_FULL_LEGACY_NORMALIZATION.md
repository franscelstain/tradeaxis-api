# Watchlist Findings

> **Physical role:** `docs/watchlist/development/findings/` — active problem/insight lineage; original observation tidak ditulis ulang.

Temuan audit/research/implementation ditempatkan langsung di folder ini agar mudah ditemukan.

## Recording / Mutability Rule

Finding lifecycle:

`OPEN -> ACCEPTED/REJECTED/RESOLVED`

- **original observation tidak boleh ditulis ulang**;
- lifecycle/status/resolution boleh ditambahkan atau direferensikan;
- finding baru harus mempunyai stable Record ID;
- finding belum mengubah strategy/implementation authority sampai ada decision/change yang sesuai.

Universal rule: [`../../authority/governance/DOCUMENT_RECORDING_STANDARD.md`](../../authority/governance/DOCUMENT_RECORDING_STANDARD.md).
