# Weekly Swing Evidence

Actual historical results.

- `backtest/` — IS/OOS and backtest proof records.
- `locks/` — evidence identity/shadow/OOS locks.
- `results/` — execution/review/result records.
- `operator_commands/` — commands used to produce/validate evidence.
- `artifacts/` — JSON/CSV evidence artifacts.
- `ledgers/` — append-heavy implementation status history.

None of these files creates current strategy by itself.
