# Retained Unsplit Legacy Sources

This directory stores only legacy sources that were **not** fully decomposed, or that remain an intentional bundle exception.

A legacy source that has reached `FULL_100_PERCENT_SEALED` split coverage must **not** retain a duplicate physical original here. Its provenance is carried by `LEGACY_SOURCE_INDEX.csv`, role-pure `LX-*` records, `LEGACY_SPLIT_RECONSTRUCTION_INDEX.csv`, and `LEGACY_SPLIT_SOURCE_CATALOG.md`.

Current strategy/governance/implementation derivatives are not stored here as legacy originals.
