# D-WS-20260819-02 — Adopt One Document, One Authoritative Role

> **Document Type:** DECISION  
> **Authoritative Role:** DECISION  
> **Status:** ISSUED  
> **Scope:** all Watchlist documentation  
> **Created:** 2026-08-19

## Decision

Adopt the rule **one physical semantic document = exactly one authoritative role**.

Cross-role references and short supporting summaries are allowed. Cross-role authority is prohibited. If information becomes independently authoritative as evidence, finding, decision, research, implementation contract, strategy, or governance, it must be recorded separately and linked.

Legacy multi-role bundle exceptions are no longer valid. A retained legacy source may remain only if its audited semantic authority is singular or if the file has one legitimate container role such as navigation, registry, status ledger, or source container.
