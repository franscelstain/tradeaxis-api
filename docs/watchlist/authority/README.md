# Watchlist Authority

`docs/watchlist/authority/` berisi dokumen yang **harus dipatuhi oleh implementation**, bukan working area biasa.

## Contents

- [`strategy/`](strategy/README.md) — canonical Weekly Swing behavior, objectives, gates, ranking, proof requirements.
- [`governance/`](governance/README.md) — aturan dokumentasi, stage lifecycle, residue, traceability, audit, dan controlled revision.

## Mutability

Keduanya menggunakan **controlled revision**. Saat implementation berjalan, programmer tidak boleh mengubah authority agar code terlihat lulus. Material revision harus mengikuti finding/evidence/decision/change-log sesuai governance.

Untuk mulai membaca Watchlist dari awal, kembali ke [`../START_HERE.md`](../START_HERE.md).
