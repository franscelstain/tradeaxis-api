# Negative Test Catalog (STRATEGY LOCKED)

The production path must reject or safely hold at least:

- secret-bearing observation/request/log/evidence;
- response for the wrong/stale date, incompatible schema, or unknown adapter mapping;
- zero/null/inconsistent OHLC, negative volume, and conflicting duplicate with “latest wins” behavior;
- canonical/publication output without observation/config/temporal lineage;
- historical resolution through current active/symbol/sector/status/config/action/factor state;
- symbol reuse mapped by text only;
- provider outage/dormancy/zero volume/current inactivity removing denominator members;
- unknown expectation treated as not-expected;
- price jump/synthetic candidate automatically verifying an action or factor;
- provider adjusted-close/raw OHLC mixing;
- any update/delete/repair of source observations, factor/event revisions, snapshots, manifests, seals, or published history;
- force promotion of an incomplete/configless/unsealed candidate;
- adjusted-price×raw-volume labeled actual turnover;
- sliding ATR reseed, skipped dependency gap, or 14-day correction-impact cap;
- a publication hash excluding a published reason/annotation;
- consumer `MAX(trade_date)`, current-table, eligibility-only, mixed-publication, or implicit prior-date fallback;
- replay using later-known master/action/calendar/status/config/formula state;
- scheduler process success labeled readable without gateway proof; and
- `BLOCKED`/missing evidence counted as pass or production ready.

Each negative case asserts no forbidden side effect, prior pointer preservation where applicable, full reasons/evidence, and a regression guard on the actual command/repository/service—not merely a doc string.
