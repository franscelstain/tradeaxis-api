# Market Data Historical Patches

This folder preserves **historical patch/session records only**. Patch notes describe what was changed under their dated contract state and are not current behavioral authority. Current V2 behavior is defined by `../book/`, `../db/`, `../registry/`, `../indicators/`, `../session_snapshot/`, and the active Blueprint/Conformance Matrix.

Any old suspension, coverage, identity, repair, source, or price-basis rule appearing in a patch record is superseded when it conflicts with current owner contracts.
