# Legacy Document Normalization Standard

Every pre-refactor source receives an `LS-MD-xxxx` identity in `records/history/LEGACY_SOURCE_INDEX.csv`. The current physical primary path and SHA1 preserve provenance. Legacy mixed verdict/status language has historical-only effect after rebaseline. No old Wxx/Campaign status may be copied into current `MD-Bxx` verification.

## Full semantic split rule

A registered pre-refactor source that materially owns more than one historical semantic role MUST be audited section-by-section. It may be physically removed only after `LEGACY_SPLIT_RECONSTRUCTION_INDEX.csv` proves every original source line is covered exactly once by an `LX-MD-*` role-pure extract. Strategy authority documents are excluded from semantic rewriting/splitting under the strategy freeze manifest.

Role-pure legacy placement:
- evidence extracts → `records/evidence/legacy/semantic/`;
- issued decision extracts → `records/decisions/legacy/`;
- historical context, finding, research, implementation, and old governance extracts → `records/history/archive/semantic/`.

No split extract is current proof. All legacy extracts remain `HISTORICAL_ONLY`.
