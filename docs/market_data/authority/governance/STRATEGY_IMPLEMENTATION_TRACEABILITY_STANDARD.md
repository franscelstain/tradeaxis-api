# Strategy-to-Implementation Traceability Standard

Current strategy is decomposed into stable rule/reference rows in `STRATEGY_TO_IMPLEMENTATION_TRACEABILITY_MATRIX.csv`. Required active rules begin `NOT_ASSESSED`; optional capability rules begin `OPTIONAL_NOT_REQUESTED`. `SATISFIED` requires current correlation-first evidence tied to a valid `MD-Bxx` Attempt/Baseline/Epoch. Historical evidence may be supporting context only.
