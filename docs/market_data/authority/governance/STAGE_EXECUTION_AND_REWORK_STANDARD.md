# Stage Execution and Rework Standard

Current stages are `MD-B00..MD-B22`. Attempt format: `MD-Bxx-Ayyy`.

`DONE` requires objective/exit criteria, required strategy coverage, current baseline, current evidence, conformant residue state, and integrity gates. A failed implementation-stage acceptance test cannot be marked DONE. Waiting dependency is active, not terminal. Re-entry must read latest attempt, open findings, dependencies, prior residue, do-not-repeat, and exact resume point.
